# GENOMESCAN-INTERNSHIP r-analysis
This directory contains R/Quarto analysis files developed during the
GenomeScan internship for exploratory analysis, threshold testing, annotation
checks, and reporting around variant interpretation workflows.

These analyses were created as practical research and validation notebooks,
typically executed in a local analysis environment as part of broader
internship experiments.

This work was created during an internship period from November 2023 to
August 2024.

The material reflects internship-driven, student-level development with a
strong emphasis on learning, experimentation, and iterative analysis. The
primary goal was to build practical experience in applied bioinformatics
data analysis, reporting, and interpretation support.

Notes:
- Analyses may rely on project-specific datasets and paths.
- Expected inputs, outputs, and assumptions can differ per file.
- Some reports were built for focused internal validation use during the
  internship period.
