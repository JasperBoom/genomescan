# GENOMESCAN-INTERNSHIP wrappers
This directory contains shell wrapper scripts developed during the GenomeScan
internship to simplify execution of recurring analysis tasks, pipeline steps,
tool runs, and environment-specific commands.

These wrappers were primarily designed as practical command-line helpers for
internal workflow execution and reproducibility during internship work.

This work was created during an internship period from November 2023 to
August 2024.

The scripts reflect internship-driven, student-level development with a
strong focus on learning, experimentation, and iterative workflow improvement.
The primary goal was to gain practical experience in bioinformatics pipeline
orchestration and tool integration in real-world settings.

Notes:
- Wrapper behavior and required arguments differ per script.
- Many scripts assume specific tools, environments, paths, or cluster settings.
- Some wrappers were built for focused internal internship workflows and may
  require adaptation for other systems.
