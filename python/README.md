# GENOMESCAN-INTERNSHIP python
This directory contains Python scripts developed during the GenomeScan
internship to support variant-processing workflows, Exomiser file preparation,
ranking, filtering, benchmarking, and dataset analysis tasks.

These scripts were built as practical workflow utilities and research helpers,
and are intended to be run from the command line as part of broader
bioinformatics pipelines.

This work was created during an internship period from November 2023 to
August 2024. The code reflects internship-driven, student-level development
with a strong focus on learning, experimentation, and iterative improvement.
The primary goal during this period was to gain hands-on experience in
applied bioinformatics, Python scripting, and production-adjacent pipeline
support.

Notes:
- Script interfaces and assumptions may vary per file.
- Input and output formats are workflow-dependent.
- Some scripts were designed for specific internal datasets and environments
  used during the internship.
